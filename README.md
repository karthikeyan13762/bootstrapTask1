# Github Clone Layout

## Overview
This project is a simple static webpage that mimics a basic layout for a GitHub-like page. The design includes a responsive header, sidebar, and main content area using Bootstrap and Font Awesome.

## Features
- **Responsive Design**: Automatically adjusts for different screen sizes.
- **Font Awesome Icons**: Includes the GitHub icon in the header.
- **Custom Styles**: Uses a minimal dark theme for all elements.
- **Sidebar and Main Content**: Organized into sections with cards for future content.

## Technologies Used
- **HTML5**
- **CSS3**
- **Bootstrap 5.3.2**
- **Font Awesome 6.4.2**
